# Intro Python Programs

Labs and short exercises from an introductory Python course. The larger projects from that course already have their own repositories: blackjack, the RLE codec, Pakudex, Sudoku, and the ray marcher.

| Path | What it is |
| --- | --- |
| `lab1` | Hello, world |
| `lab2` | Four-function calculator |
| `lab3` | Scientific calculator |
| `lab4` | Numeric base conversion |
| `lab5` | Connect Four |
| `lab7`, `lab8` | Cowsay, then dragons |
| `exercises` | Armstrong numbers, time conversion, octal, a phone-number table, and removing gray from an RGB value |

Run a file with `python` from its folder. For example:

```bash
python lab5/connect_four.py
```
